void encrypt (\begin{DoxyParamCaption}\item[{char}]{message}{\+[$\,$]\+, }\item[{int}]{offset}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [extern]}}



Core Caesar cipher shift function (used for both encryption and decryption). 


\begin{DoxyItemize}
\item Shifts alphabetical characters in the given message by the specified offset. It handles both uppercase and lowercase letters independently while leaving spaces, punctuation, and numbers untouched. It safely processes negative offsets and offsets greater than 26 using modulo arithmetic.
\item 
\begin{DoxyParams}{Parameters}
{\em message} & The null-\/terminated string to be modified in-\/place. \\
\hline
{\em offset} & The number of positions to shift the characters (can be negative). \\
